## 💡 系统用途与全场景应用框架 🌐

**Nexora Agent** 是一款面向个人智囊、企业私域与自动化运维的 **零信任本地主权 AI 自动化中枢** 🛡️。它将各大公有云/私有化大模型的认知能力与微信、飞书、QQ、钉钉等全渠道社交终端及物理操作系统无缝无痕无感连接 🔗。

### 1. 👤 全渠道个人 AI 数字分身
* 💬 **微信 / 飞书 / QQ 消息自动托管**：手机不在身旁或工作繁忙时，助手可在后台实时接管特定好友或群聊，使用带有您个人专属记忆的语气与知识库准确回复。
* 🧠 **增量长期记忆萃取**：自动从对话中提取您的工作偏好、习惯与既定日程，保存至本地纯文本 Markdown 库，越用越懂得您的需求。

### 2. 🏢 企业级私域流量与客服自动化
* 🎧 **全双工智能客服**：无需昂贵的 SaaS 系统，在本地电脑即可拉起 7×24 小时微信/飞书客服机器人，支持多图发送、文档解析与智能故障排除。
* 🛡️ **防封号双路路由**：社交平台通信数据包纯本地 IP 直连，大模型 API 走加密隧道，技术层面规避风控封号风险。

### 3. 🖱️ 极客与开发者 RPA 桌面自动化
* 🖥️ **物理桌面控制**：AI 可直接分析当前屏幕内容，利用原生的 `user32.dll` 驱动模拟物理鼠标点击与键盘敲击，自动完成表单填写、软件测试与数据抓取。
* 📦 **离线安全沙箱**：基于隔离免安装 Node.js LTS 环境，即使执行复杂 Python/Shell 脚本，也不会影响宿主机的真实操作系统环境。

### 1. ⚡ Agent (控制台面板 `console-view`)
* 🚀 **核心功能**：软件的核心总控台。在此可一键控制本地 Agent 服务的拉起与终止。
* 🔘 **主要控件与界面元素**：
  * **主启动/停止按键**：点击一键启动或关闭 Agent 服务后台线程。
  * **实时三色指示灯**：🔴 **已停止**、🟡 **启动中 (沙箱挂载中)**、🟢 **已就绪**。
  * **端口与加载百分比**：实时显示网关监听的本地端口（默认 `18789`）及 0-100% 加载进度。
* ⚙️ **底层机制**：触发后台自动挂载 `.node-sandbox` 免安装便携环境，拉起 Gateway 核心主进程。

---

### 2. ⚡ Clash (网络加速通道 `acceleration-view`)
* 🌐 **核心功能**：管理内置的 Mihomo 加速内核与防封安全代理路由。
* 🔘 **主要控件与界面元素**：
  * **代理模式切换**：支持 `规则分流 (Rule)`、`全局加密 (Global)` 与 `直连模式 (Direct)` 自由切换。
  * **订阅节点配置**：支持导入自定义加密加速订阅链接与节点选择。
  * **NO_PROXY 白名单字典**：内置微信、飞书、QQBot 官方服务器域名白名单，强行绕过代理。
* 🛡️ **底层机制**：社交平台数据包纯本地物理 IP 传输（技术防封号），大模型流量走高隐蔽加密加速。

---

### 3. 📊 数据中心 (Data Center Dashboard `data-center-view`)
* 📈 **核心功能**：全盘可视化系统运维与性能 Telemetry 实时仪表盘。
* 🔘 **主要控件与界面元素**：
  * **CPU & 内存占用折线图**：动态刷新展示 CPU 使用率 (%) 与内存占用 (MB/GB) 变化。
  * **网络吞吐带宽流速**：实时显示上行 (Upload) 与下行 (Download) KB/s 流量速率。
  * **Token 消耗分布图**：按模型与时间维度展示输入 Token、输出 Token 及累计消耗。
* 💻 **底层机制**：通过专用的 IPC 通道实时采集沙箱与系统的硬件计数器，渲染为 ECharts 动态图表。

---

### 4. 💬 模型会话 (模型交互主视界 `chat-view`)
* 💬 **核心功能**：与本地或云端大模型进行实时全功能交互。
* 🔘 **主要控件与界面元素**：
  * **模型切换下拉框**：随时切换当前生效的大模型（如 DeepSeek, Qwen, Ollama 等）。
  * **富媒体气泡区**：完美支持 Markdown 语法、代码高亮一键复制、LaTeX 数学公式、本地图片/视频/音频直接预览播放。
  * **清空/新建会话**：快速重置当前上下文或开启独立对话空间。
* 🔄 **底层机制**：内置会话无缝滚存回路 (Session Overflow Rollover)，当上下文超出 Token 阈值时自动提取摘要并滚存至新会话。

---

### 5. 📂 会话归档 (会话历史管理 `session-archive-view`)
* 📁 **核心功能**：检索、管理与导出所有的历史对话记录及溢出滚存备份。
* 🔘 **主要控件与界面元素**：
  * **历史列表卡片**：按时间倒序排列展示过往的所有对话会话与摘要信息。
  * **检索搜索框**：支持根据关键词快速过滤查找历史聊天记录。
  * **导出与备份**：支持将会话记录一键导出为纯文本或 Markdown 格式文件。

---

### 6. 🧠 模型配置 (模型供应商矩阵 `config-view`)
* 🔑 **核心功能**：统一配置大模型厂商 API Key、服务端点与视觉对齐参数。
* 🔘 **主要控件与界面元素**：
  * **厂商启停开关**：支持一键启用/禁用 DeepSeek、阿里云百炼 (Qwen)、SiliconFlow、OpenAI、Ollama 等供应商。
  * **API Key 填报区**：加密字典本地存储，凭证绝对不出本机。
  * **连通性探针测试**：点击「测试连接」，瞬间返回 API 连通延迟 (ms) 与可用状态。
  * **视觉模型自动对齐 (Vision Alignment)**：自动将包含图片理解能力的模型标记为 `text+image` 模式。

---

### 7. 📱 通讯管理 (社交渠道托管 `communication-view`)
* 📱 **核心功能**：托管微信、飞书、QQBot、Slack、Matrix 等全渠道社交机器人。
* 🔘 **主要控件与界面元素**：
  * **渠道状态卡片**：展示各平台的连接状态（🟢 运行中 / 🔴 已停止）。
  * **扫码绑定按键**：点击一键生成二维码弹窗，微信/飞书手机扫码即可确认登录。
  * **参数配置面板**：配置飞书 App ID / App Secret、QQBot AppID 等机器人凭证。
* 🔄 **底层机制**：内嵌 v3 高可用重连引擎，遇局域网断网自动启动指数退避静默热重连，45 秒内自适应上线。

---

### 8. 🎭 模型角色 (AI 人格与提示词预设 `roles-view`)
* 🎭 **核心功能**：定制 AI 助手的系统 Prompt 提示词、语气、性格与专业领域。
* 🔘 **主要控件与界面元素**：
