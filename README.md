## 💡 系统用途与全场景应用框架

**Nexora Agent** 是一款面向个人智囊、企业私域与自动化运维的 **零信任本地主权 AI 自动化中枢**。它将各大公有云/私有化大模型的认知能力与微信、飞书、QQ、钉钉等全渠道社交终端及物理操作系统无缝无痕无感连接。

```mermaid
graph TD
    A[用户及团队终端<br/>微信 / 飞书 / QQ / 网页] -->|安全隔离通讯| B(Nexora Agent 本地主权中枢)
    B -->|零信任加密通道| C[大模型矩阵<br/>DeepSeek / 阿里云百炼 / SiliconFlow / 离线Ollama]
    B -->|本地自动化控制| D[物理操作系统控制<br/>Win32 API / 屏幕截屏 / 文件读写]
    B -->|本地媒体生成| E[技能中心<br/>文生图 / 文生视频 / 离线 TTS 语音 Matrix]
    B -->|全盘数据监控| F[数据中心 Dashboard<br/>CPU / GPU / Token 消耗 / 流量流速]
```

### 1. 全渠道个人 AI 数字分身
* **微信 / 飞书 / QQ 消息自动托管**：手机不在身旁或工作繁忙时，助手可在后台实时接管特定好友或群聊，使用带有您个人专属记忆的语气与知识库准确回复。
* **增量长期记忆萃取**：自动从对话中提取您的工作偏好、习惯与既定日程，保存至本地纯文本 Markdown 库，越用越懂得您的需求。

### 2. 企业级私域流量与客服自动化
* **全双工智能客服**：无需昂贵的 SaaS 系统，在本地电脑即可拉起 7×24 小时微信/飞书客服机器人，支持多图发送、文档解析与智能故障排除。
* **防封号双路路由**：社交平台通信数据包纯本地 IP 直连，大模型 API 走加密隧道，技术层面规避风控封号风险。

### 3. 极客与开发者 RPA 桌面自动化
* **物理桌面控制**：AI 可直接分析当前屏幕内容，利用原生的 `user32.dll` 驱动模拟物理鼠标点击与键盘敲击，自动完成表单填写、软件测试与数据抓取。
* **离线安全沙箱**：基于隔离免安装 Node.js LTS 环境，即使执行复杂 Python/Shell 脚本，也不会影响宿主机的真实操作系统环境。

### 4. 离线高保密智囊与多媒体创作
* **零数据外泄**：所有聊天历史、凭证与记忆数据库 100% 存储于本地磁盘，零数据上传第三方中间件。
* **原生音视频创作**：集成离线 Sherpa-Onnx 神经网络语音合成、文生图与文生视频插件，气泡内直接预览与播放生成的多媒体文件。

## 🖥️ 界面菜单与功能模块全解析

Nexora Agent 采用了极简现代的赛博暗黑风 UI 设计，导航栏位于软件左侧，各功能模块分工清晰，便于一站式管理：

```text
 ┌───────────────────┬────────────────────────────────────────────────────────────────────────┐
 │ Nexora Agent      │ 🟢 核心服务就绪 | 端口: 18789  [ 终止服务 ] [ 重启网关 ]                   │
 ├───────────────────┼────────────────────────────────────────────────────────────────────────┤
 │ 💬 模型会话       │  ┌───────────────────────────────┐ ┌──────────────────────────────────┐  │
 │ 🧠 模型配置       │  │ 会话列表 (Rollover 自动支持)  │ │ 当前对话气泡视界                 │  │
 │ 📱 通讯管理       │  │ - 默认微信对话                │ │ [AI] 你好！我是您的本地主权AI助手│  │
 │ 🛠️ 技能中心       │  │ - 工作助理                    │ │ [MEDIA] 渲染本地生成的图片/视频   │  │
 │ 📊 数据中心       │  └───────────────────────────────┘ └──────────────────────────────────┘  │
 │ 🎙️ 语音配置       │  模型选择: [ agnes-ai/agnes-2.0-flash ▼ ]   [ 探针测试 ] [ 清空会话 ]    │
 │ ⚙️ 系统设置       │                                                                        │
 └───────────────────┴────────────────────────────────────────────────────────────────────────┘
```

### 1. 顶部控制栏 (Top Control Matrix)
* **状态指示灯**：
  * 🔴 **红色**：核心服务已停止，无法处理消息与请求。
  * 🟡 **黄色**：系统正在拉起 Node.js 本地沙箱与网络加速内核。
  * 🟢 **绿色**：**核心服务就绪！** 表示网关服务已成功在本地端口（默认 `18789`）开启监听，随时响应连接。
* **启动 / 终止服务按键**：一键切换网关与沙箱的启动与停止。
* **重启网关 / 重置按键**：遇到异常网络波动或需要生效新插件时，可在此强行重启网关。

### 2. 💬 模型会话 (Chat & Interactive Sessions)
* **主对话窗口**：支持 Markdown 渲染、代码高亮一键复制、LaTeX 公式展示及本地媒体文件（图片、视频、音频）直显。
* **模型快速切换下拉框**：实时显示当前可用的云端与本地大模型，随时无缝切换。
* **会话无缝滚存 (Session Overflow Rollover)**：当单个会话累积的 Token 接近模型上限时，滚存引擎将自动总结上文历史并创建新会话，对话流畅不断层。
* **快捷会话管理**：支持新建会话、删除历史会话、一键清空上下文以及会话搜索。

### 3. 🧠 模型配置 (Model Provider Matrix)
* **供应商统一管理**：预置并支持接入 `agnes-ai`、`DeepSeek`、`阿里云百炼 (Qwen)`、`SiliconFlow (硅基流动)`、`OpenAI`、`Ollama` 等国内外主流大模型厂商。
* **API Key 安全存储**：填入的凭证 100% 使用本地加密字典落盘，绝不出本机。
* **识图/视觉模型对齐 (Vision Model Alignment)**：自动识别带有图像理解能力的模型（如 `vision` / `multimodal`），确保图像输入时自动匹配多模态解析通道。
* **模型连通性探针**：点击「测试连接」，系统自动向指定 API 发送探针数据包，反馈延迟毫秒数与服务可用性。

### 4. 📱 通讯管理 (Channel Manager)
* **全渠道卡片矩阵**：
  * **微信 (WeChat)**：支持网页/iPad 协议扫码登录，内嵌 v3 指数退避重连算法。
  * **飞书 (Feishu)**：支持企业自建应用 App ID 与 App Secret 绑定，支持群聊与私聊托管。
  * **QQBot**：官方机器人 API 接入，自动过滤指令与消息响应。
  * **Slack / Matrix / Voice Call**：全双工扩展适配。
* **二维码弹窗交互**：点击「扫码绑定」，自动生成高清晰 Base64 二维码，手机扫描即可完成秒级托管。

### 5. 🛠️ 技能中心 (Skill Center)
* **内置技能生态**：
  * 📷 **桌面抓屏 (Screen Capture)**：调用高清截屏工具截取当前屏幕，自动传给视觉大模型分析。
  * 🖱️ **物理桌面操控 (Desktop Control)**：支持用户模拟点击、输入、快捷键组合等物理级 Windows RPA 操作。
  * 🎨 **文生图插件 (Image Generator)**：通过自然语言提示词直接生成高清图片并直接呈现在聊天气泡中。
  * 🎬 **文生视频插件 (Video Generator)**：输入画面描述生成动态视频片段。
* **技能热加载与开关**：开发者可随时启用或禁用特定技能，灵活控制 AI 的操作权限。

### 6. 📊 数据中心 (Data Center Dashboard)
* **可视化 Telemetry 仪表盘**：
  * **CPU & 内存占用率**：实时监控本地沙箱与网关占用的资源比例。
  * **网络吞吐量 (Network I/O)**：展示实时上行与下行流量速率曲线。
  * **Token 消耗与分布曲线**：直观统计输入 Token、输出 Token 及累计消耗量。
  * **请求响应延迟分布**：记录大模型调用的首字延迟（TTFT）与平均响应耗时。

### 7. 🎙️ 语音配置 (Offline Voice Matrix)
* **离线语音推理引擎**：基于 Sherpa-Onnx 神经网络，实现中英混合高质量 TTS 文本转语音。
* **VAD 人声滑动窗口**：通过滑动窗口算法判定用户说话的起始与静音停顿，实现连续语音对话。
* **Windows SAPI 降级兜底**：当缺少神经网络模型权重时，系统自动无缝降级至 Windows 本地 SAPI 音频合成，确保 100% 可发出声音。

### 8. ⚙️ 系统设置与自愈诊断 (Settings & Diagnostics)
* **内核网络加速 (Mihomo Core)**：可选开启内置代理内核，为云端大模型 API 提供稳定加速。
* **白名单配置 (NO_PROXY)**：管理不经过代理的本地与社交平台域名白名单。
* **系统完整性探针 (Doctor Probe)**：一键诊断系统依赖、端口占用、权限策略与配置文件完整性。
* **日志视界 (Log Telemetry Window)**：实时流式输出系统 stdout/stderr 日志，便于高级用户排查疑难问题。

## 👨‍💻 开发者二次开发与插件扩展

### 1. 本地构建与源码调试
```bash # 克隆项目代码仓库
git clone https://github.com/2014-y/NexoraAgent.git
cd NexoraAgent

# 安装本地依赖
npm install

# 启动 Electron 本地开发调试模式
npm run app:start

# 构建一键安装包 (NSIS Installer)
npm run app:dist
```

### 2. 编写自定义技能插件
在 `plugins/my-custom-skill/` 目录下创建 `index.js`：

```javascript
'use strict';

class CustomSkillPlugin {
  constructor(context) {
    this.ctx = context; // 注入系统主权上下文
  }

  async onload() {
    this.ctx.log?.info('[CustomSkill] 技能插件成功加载');
    // 注册自定义路由或工具监听
  }

  async onunload() {
    this.ctx.log?.info('[CustomSkill] 技能插件已卸载');
  }
}

module.exports = CustomSkillPlugin;
```
