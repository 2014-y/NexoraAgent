## 🐣 小白零门槛一键安装与使用全指南 (Novice Guide) 💡

即使您完全没有任何编程基础或电脑技术背景，只需按照以下 **4 个极简步骤**，即可在 **3 分钟内** 完成搭建并让 AI 助手代替您在微信、飞书或 QQ 中自动答复！✨

```mermaid
flowchart LR
    A[📦 1. 下载一键安装包] --> B[🚀 2. 点击「启动服务」]
    B --> C[🔑 3. 填入 API Key 脑区]
    C --> D[📱 4. 手机微信扫码授权]
    D --> E[🎉 托管成功！AI 自动代答]
```

> [!TIP]
> 💡 **准备工作（仅需 2 样东西）**：
> 1. 一台普通的 Windows 10 或 Windows 11 电脑（**不需要高性能显卡**）。
> 2. 一个大模型厂商的 API Key（推荐使用 **DeepSeek** 或 **阿里云百炼**，注册即送免费试用额度）。

### 🚀 步骤一：一键下载与傻瓜式安装
1. **下载安装包**：在 [Windows 2.0.5 发布页](https://github.com/2014-y/NexoraAgent/releases/tag/v2.0.5) 下载 `Nexora-Agent-Setup-2.0.5.exe`（Windows x64）。其他版本见 [Releases](https://github.com/2014-y/NexoraAgent/releases)。
2. **双击安装**：双击运行下载好的 `.exe` 文件。向导会自动选择最佳路径安装，并在桌面建立 `Nexora Agent` 赛博风快捷启动图标。
3. **零环境依赖**：软件**内置了便携式免安装 Node.js LTS 沙箱**，您**完全不需要**手动下载 Python、Node.js、Git 或配置任何复杂的环境变量！

---

### 🟢 步骤二：启动核心服务与三色灯识别
1. 打开桌面快捷方式 `Nexora Agent`。
2. 在左侧主界面顶部找到 **「🚀 启动 Nexora Agent」** 按钮并点击。
3. 观察左上角的状态指示灯变化：
   * 🔴 **红色**：服务停止中。
   * 🟡 **黄色**：系统正在自动挂载本地运行环境与网关资源。
   * 🟢 **绿色**：**核心服务就绪！** 出现 `端口: 18789` 提示，表示 AI 大脑中枢已在本地成功唤醒。

---

### 🔑 步骤三：绑定大模型“大脑” (API Key 配置)
1. 点击左侧导航栏 **「🧠 模型配置」**。
2. 在供应商列表中勾选您使用的服务商（如 `DeepSeek` 或 `阿里云百炼`）。
3. 复制您在厂商官网申请到的 API Key（格式如 `sk-xxxxxxxxx`），粘贴到密钥输入框中。
4. 点击右侧 **「测试连接」** 按键。若显示 `🟢 连通成功 (延迟 xx ms)`，代表 AI 大脑已成功连通！
5. 点击左侧 **「💬 模型会话」** 发送“你好”，若收到 AI 回复，说明配置完全正确。

---

### 📱 步骤四：手机扫码，一键托管微信 / 飞书 / QQ
1. 点击左侧导航栏 **「📱 通讯管理」**。
2. 在微信或飞书卡片上点击 **「扫码绑定」** 按键。
3. 界面会弹出一个清晰的二维码弹窗。
4. 掏出手机打开微信或飞书扫描二维码，并在手机屏幕上点击 **「确认登录」**。
5. 当卡片状态亮起 **🟢 已绑定 (运行中)** 时，大功告成！助手即刻开始替您接管日常对话。

### 1. ⚡ 控制面板 (`console-view`)
* 🚀 **核心定位**：整个 Nexora Agent 软件的核心总控台与生命周期管理者。
* 🔘 **主要控件与界面元素**：
  * **「启动/终止 Nexora Agent」主按键**：一键平滑拉起或平滑关闭后台 Node.js 沙箱与网关主线程。
  * **三色运行状态指示灯**：
    * 🔴 **已停止**：网关服务处于关闭休眠状态，零 CPU/内存占用。
    * 🟡 **启动中**：正在挂载便携沙箱、解压核心资源、检查端口与启动网关。
    * 🟢 **服务就绪**：网关已在本地端口（默认 `18789`）开启监听，随时响应全渠道请求。
  * **加载百分比与端口标识**：实时显示当前网关启动进度（0% ~ 100%）与监听地址（`http://127.0.0.1:18789`）。
  * **运行状态微型趋势图 (Canvas Mini-Chart)**：在侧栏底部实时绘制 CPU 占用与网络吞吐的波动波形曲线。
* ⚙️ **底层机制**：点击启动后，主进程执行 `gateway-boot-harden.js`，自动擦除异常残留锁并挂载便携 `.node-sandbox` 环境。

---

### 2. 📱 通讯管理 (`communication-view`)
* 📱 **核心定位**：一站式托管与管理微信、飞书、QQBot、Slack、Matrix 等全渠道社交机器人。
* 🔘 **主要控件与界面元素**：
  * **渠道状态卡片**：展示微信、飞书、QQ 等通道的运行状态（🟢 运行中 / 🔴 已停止）。
  * **微信「扫码绑定」按键**：点击一键生成高清 Base64 二维码弹窗，微信手机扫码即可完成授权。
  * **飞书 / QQBot 凭证配置**：配置飞书 App ID / App Secret、QQBot AppID / Token 等官方凭证。
* 🔄 **底层机制**：内嵌 v3 高可用重连引擎，遇局域网断网自动启动指数退避静默热重连，45 秒内自适应上线。

---

### 3. 🧠 模型配置 (`config-view`)
* 🔑 **核心定位**：统一管理与配置各大公有云及本地私有大模型的 API Key 与端点。
* 🔘 **主要控件与界面元素**：
  * **厂商启停开关**：支持一键开关 DeepSeek、阿里云百炼 (Qwen)、SiliconFlow、OpenAI、Ollama、LM Studio 等服务商。
  * **API Key & Base URL 填报框**：凭证密文存储于本地配置文件，绝对不出本机。
  * **「测试连接」探针按钮**：向对应 API 发送轻量探针包，实时反馈响应延迟（ms）与可用状态。
  * **视觉模型自动对齐开关 (Vision Model Auto-Align)**：自动将包含图片理解能力的模型标记为 `image` 兼容，防止传图时报错。

---

### 4. 🎭 模型角色 (`roles-view`)
* 🎭 **核心定位**：定制与预设 AI 助手的 System Prompt 系统提示词、语气、性格与专业领域。
* 🔘 **主要控件与界面元素**：
  * **预设角色卡片库**：内置代码专家、翻译官、私域客服、文案大师、学术润色师等角色模板。

## 👨‍💻 开发者二次开发与插件扩展 🚀

### 1. 本地构建与源码调试

macOS 支持：在 Mac 上运行 `npm run app:dist:mac` 构建对应架构的 DMG/ZIP，包含独立 Node/npm 运行时。环境要求、验证和签名说明见 [macOS 构建文档](docs/macos-build.md)。

```bash
# 克隆项目代码仓库
git clone https://github.com/2014-y/NexoraAgent.git
cd NexoraAgent

# 安装本地依赖
npm install

# 启动 Electron 本地开发调试模式
npm run app:start

# 构建一键安装包 (NSIS Installer)
npm run app:dist
```

### 2. 编写自定义技能插件
在 `plugins/my-custom-skill/` 目录下创建 `index.js`：

```javascript
'use strict';

class CustomSkillPlugin {
  constructor(context) {
    this.ctx = context; // 注入系统主权上下文
  }

  async onload() {
    this.ctx.log?.info('[CustomSkill] 技能插件成功加载');
    // 注册自定义路由或工具监听
  }

  async onunload() {
    this.ctx.log?.info('[CustomSkill] 技能插件已卸载');
  }
}

module.exports = CustomSkillPlugin;
```
